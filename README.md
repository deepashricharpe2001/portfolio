## :dart: About

A responsive personal portfolio website built with Next.js and TypeScript, showcasing my professional experience as a Data Scientist, skills in Machine Learning and Python development, and data science projects with a clean, modern design.

## :sparkles: Features

:heavy_check_mark: Projects page showcasing 6 data science projects including ML models and data analysis\
:heavy_check_mark: Blog page integrated with Medium (@deepashricharpe0)\
:heavy_check_mark: Tech news page featuring latest industry updates\
:heavy_check_mark: About page with professional background, skills, and experience\
:heavy_check_mark: Contact page for professional inquiries\
:heavy_check_mark: Downloadable resume (PDF)

## :rocket: Technologies

The following tools were used in this project:

- [Next.js](https://nextjs.org/)
- [Node.js](https://nodejs.org/en/)
- [React](https://pt-br.reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [RSS Parser](https://www.npmjs.com/package/rss-parser)
- [React Type Animation](https://www.npmjs.com/package/react-type-animation)

## :white_check_mark: Requirements

Before starting :checkered_flag:, you need to have the following requirements:

- [Git](https://git-scm.com)
- [Node.js](https://nodejs.org/en/) version 18.17 or higher
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) package manager
- A [Discord](https://discord.com/) account (for webhook functionality)
- Basic knowledge of TypeScript and React
- A code editor like [VS Code](https://code.visualstudio.com/) (recommended)

## :sparkles: Portfolio Highlights

- **Data Science Projects**: Diamond Price Prediction, Movie Recommendation System, Swiggy Data Analysis, Electric Vehicle Analysis, AMCAT Data Analysis, MLOps Pipeline
- **Skills**: Python, SQL, Machine Learning, Deep Learning, Data Visualization, MLOps
- **Experience**: Data Science Intern at Innomatics Research Labs
- **Blog Integration**: Articles automatically fetched from Medium

## :checkered_flag: Starting

```bash
# Clone this project
$ git clone https://github.com/deepashricharpe2001/myportfolio

# Access
$ cd portfolio

# Install dependencies
$ npm install

# Run the project
$ npm run dev

# The server will initialize in the <http://localhost:3000>
```
